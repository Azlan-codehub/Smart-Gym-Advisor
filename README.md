Smart Gym Advisor:

A C++ console application that builds personalized gym workout and diet plans based on real user input — built to give free, practical fitness guidance to people who can't afford a personal trainer.

The Problem:

Me and my two groupmates went to the gym without any plan and were told a personalized routine only comes with a paid trainer package. Not affordable for students. So for our 2nd semester C++ lab project, we built a tool that gives people that same guidance for free.

Features:

- Calculates BMI and daily calorie/protein needs (BMR-based, gender-specific)
- Goal-based plans: Weight Loss, Muscle Gain, Strength & Core Training, Stretching
- Injury-aware routines (adjusts exercises for back, knee, shoulder issues)
- Custom 3-day or 5-day weekly workout schedules
- Built-in nutrition guide (protein, carb, and calorie-rich foods)
- Full input validation using do-while loops

Concepts Used:

Variables, loops (while/do-while), conditionals (if-else, switch-case), 2D arrays, functions, input/output handling

How to Run:

```bash
g++ smart_gym_advisor.cpp -o gym_advisor
./gym_advisor
```
